# Python Mini Projects

Small Python programs I wrote while learning, each practising one core concept.

| Program | What it does | Concept |
|---|---|---|
| ATM Machine ( OOP ).py | PIN-protected ATM with balance, deposit and withdraw | Classes and objects |
| Calculator ( Match Case ).py | Calculator for +, -, * and / | match-case |
| Palindrome ( for Loop ).py | Checks if a word reads the same backwards | for loop |
| Polymorphism ( Payment Process ).py | Pays through Cash, UPI, Card, NetBanking or Wallet | Polymorphism |
| Remove Duplicates.py | Removes repeated numbers from a list | Lists, loops |
| Tourist ( Inheritance ).py | Shows details of places around Tirunelveli | Inheritance |
| Voter Eligible.py | Checks voting eligibility by age and country | if / elif / else |

Run any file with: `python "filename.py"` (Python 3.10 or newer, because of match-case).
